Installer

  1. Touche le bouton vert, puis ouvre le fichier téléchargé.
  2. Si Android bloque : Paramètres → autorise ton navigateur à installer des applis inconnues, puis reviens.
  3. Touche Installer. Si Play Protect avertit : Plus de détails → Installer quand même.
  4. Mise à jour : installe simplement par-dessus. Ne désinstalle pas, tes données seraient effacées.

Les changements d'interface arrivent tout seuls à l'ouverture de l'appli. Cette page ne contient aucune donnée personnelle : tes clients, routines et rendez-vous restent uniquement sur ton téléphone.
